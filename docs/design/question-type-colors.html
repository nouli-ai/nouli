Where the color goes

The type label, Question heading, Options/Levels heading, Send label, result bars, and decision card use the type accent. Context, model status, and body text stay neutral. Inactive type labels retain a muted tint; the active label also gets brackets and bold weight.

Color means type

A No answer keeps the Yes / No color. Choice winners and score values keep their type color too. The colors identify the kind of question; labels and numbers explain the answer. Contrast values above are measured against #15191D.

Terminal rendering

True color uses the specified hex values. The 256-color preview finds a nearby fixed xterm color using indices 16–255. Each swatch shows both values so the final implementation can match the preview.

Current implementation reference

The current form uses one teal accent: ANSI index 37, approximately #00AFAF. These are six proposed alternatives for review.
