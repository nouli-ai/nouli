Nouli is a decision graph. It runs decision models over many turns and feeds earlier decisions into later ones: each turn adds facts and a new question, and the model answers it with the whole history in view.

macOS$brew install standing-desks/tap/nouli
Linux$curl -fsSL https://standing-desks.github.io/nouli/install.sh | sh

interactive mode

Open a session.
Ask as you go.

Add context, write a plain-text question, and choose Yes / No, Choose one or Score. Shift-Tab changes the type; Tab moves fields. Press Enter to send from Context or Question. In Options/Levels, Enter adds an item and a second Enter sends. Add new information to reconsider a choice using the same options.

$nouli open travel

A session keeps every fact, question and answer. Add a turn and the model answers its new question with all of it in view. Branch to try something else. Blend to put separate histories together.

Give it
a turn.

  1. Install.
    $brew install standing-desks/tap/nouli

    On Linux, use the download installer.

  2. Add a provider. Define one in ~/.nouli/config.toml (how), then log in once:
    $nouli auth login typesafe
  3. Open a session. Add context and a plain question in the form:
    $nouli open travel
