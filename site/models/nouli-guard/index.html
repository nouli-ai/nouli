Nouli Guard

Hate-speech classification

Nouli Guard is an English hate-speech classifier that returns probabilities for no, unclear, and yes. It combines fine-tuned Ettin-1B and ModernBERT-large encoders with a frozen ensemble and calibration.

Quickstart with Nouli CLI

Requires Python 3.12, the HF CLI, and Nouli CLI 0.4.2. Hugging Face hosts the files; inference runs on your machine. The Python server loads the weights, and Nouli runs the supplied decision workflow. No hosted API key is required.

In the first terminal:

Terminal 1 · prepare and serve
hf download nouli-ai/nouli-guard --revision v1.0.0 --local-dir ./nouli-guard
cd nouli-guard
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python prepare.py --text "I disagree with your argument, but I appreciate you explaining it."
python serve.py --device cpu

Once the server reports ready, open a second terminal in nouli-guard:

Terminal 2 · run the workflow
nouli --config nouli/nouli.toml --store ./.nouli-store \
  workflow run nouli/example-workflow.json --json

The example uses CPU. On a configured CUDA host, start the server with --device cuda. Rerun prepare.py with your text or file before running another workflow.

Base models and training data

  • jhu-clsp/ettin-encoder-1b
  • answerdotai/ModernBERT-large

Training data: ucberkeley-dlab/measuring-hate-speech; 19,944 training comments.

Trained on human annotation distributions for hate-speech classification. Source revisions and provenance.

Limitations

  • Evaluated on one historical English corpus. Human study-panel labels do not define every moderation policy.
  • Supports the fixed no/unclear/yes output; general safety and policy-compliance coverage is not established.
