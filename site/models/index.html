The Nouli harness

Run model workflows
with Nouli.

Nouli's terminal app, CLI and Rust library record decisions and the facts and earlier answers they use. Each model release documents the inputs, dependencies and workflow for its own task.

Hugging Face hosts the files. Inference runs on your machine; a hosted inference key is not required. The CLI and library are MIT-licensed. See each model card for its license and upstream notices.
