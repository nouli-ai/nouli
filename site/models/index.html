The Nouli harness

Run model workflows
with Nouli.

Nouli's terminal app, CLI and Rust library record decisions and the facts and earlier answers they use. Each model release includes an adapter and workflow for its own task.

Hugging Face hosts the files. Inference runs on your machine; a hosted inference key is not required. The CLI and library are MIT-licensed. Model distributions are Apache-2.0 with upstream notices.
