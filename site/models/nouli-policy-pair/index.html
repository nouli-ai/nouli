Nouli Policy Pair

Policy extraction and evidence checks

Evaluate a written policy against the facts of a case. A policy extractor and evidence model work with Nouli to return TRUE, FALSE or UNKNOWN.

Research preview, evaluated on bounded synthetic policies and narratives. The full pair requires the documented CUDA setup.

Get it on Hugging Face ↗Run locally ↓

How they work together

The extractor turns the policy into executable rules. The evidence model checks which required facts the supplied information supports. Nouli applies the rules, including calculations and comparisons, to reach the decision.

Quickstart with Nouli CLI

Requires Python 3.10 or newer, the HF CLI, and the documented CUDA environment. The supplied bootstrap pins Nouli CLI 0.5.1. Public base weights are downloaded separately during setup.

Download the complete repository:

Terminal
hf download nouli-ai/nouli-policy-pair --revision 7de8e7f56085068f9cc380be829455b197300ebe --local-dir ./nouli-policy-pair
cd nouli-policy-pair

Complete the runtime setup: build the native tools, open the pinned CUDA container, install dependencies, fetch the bases and generate inference/local/config.json.

Then run the bundled example from the prepared runtime:

Terminal
.live-venv/bin/python inference/live_pair.py \
  --config inference/local/config.json --device cuda \
  --policy inference/examples/policy.txt \
  --story inference/examples/age-eligibility-story.txt \
  --taxpayer 'Mira' --other 'Tomas' --tax-year 2025 \
  --output outputs/live.json

Read outputs/live.json for the decision. To evaluate your own case, replace the policy, story and query values. The setup guide also covers B-only execution with a saved program and offline reuse.

Limitations

  • Evaluated on bounded synthetic policies and narratives. Real-world tax eligibility is unvalidated.
  • Policy interpretation and evidence checks can make errors. Missing or unsupported facts can produce UNKNOWN.
  • Full-pair use requires the documented CUDA setup. A clean installation on unrelated hardware remains unverified.
