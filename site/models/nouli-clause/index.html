Nouli Clause

NDA evidence and entailment

Nouli Clause evaluates a fixed checklist of 17 NDA hypotheses. An Ettin-150M evidence retriever selects passages for an Ettin-1B decision encoder, which returns entailment, contradiction, or not-mentioned probabilities.

Quickstart with Nouli CLI

Requires Python 3.12, the HF CLI, and Nouli CLI 0.4.2. Hugging Face hosts the files; inference runs on your machine. The Python server loads the weights, and Nouli runs the supplied decision workflow. No hosted API key is required.

In the first terminal:

Terminal 1 · prepare and serve
hf download nouli-ai/nouli-clause --revision v1.0.0 --local-dir ./nouli-clause
cd nouli-clause
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python prepare.py --file examples/nda.txt
python serve.py --device cpu

Once the server reports ready, open a second terminal in nouli-clause:

Terminal 2 · run the workflow
nouli --config nouli/nouli.toml --store ./.nouli-store \
  workflow run nouli/example-workflow.json --json

The example uses CPU. On a configured CUDA host, start the server with --device cuda. Rerun prepare.py with your text or file before running another workflow.

Base models and training data

  • jhu-clsp/ettin-encoder-1b
  • jhu-clsp/ettin-encoder-150m

Training data: reuben256/contract-nli; 337 training contracts / 5,729 hypothesis decisions. The official source is Stanford ContractNLI, with CC-BY-4.0 attribution.

Trained on ContractNLI decision labels and human-annotated evidence spans. Source revisions and provenance.

Limitations

  • Supports the fixed 17-hypothesis NDA checklist, not arbitrary contract questions.
  • Retrieval errors can affect decisions. A retrieval miss does not establish that a statement is absent from the contract.
