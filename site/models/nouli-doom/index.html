Nouli Doom

ViZDoom corridor control

Nouli Doom is a PPO-trained policy for ViZDoom Deadly Corridor at skill 5. The inference export contains the actor network and maps structured game state to move, strafe, turn, and fire decisions.

Quickstart with Nouli CLI

Requires Python 3.12, the HF CLI, and Nouli CLI 0.4.2. Hugging Face hosts the files; inference runs on your machine. The Python server loads the weights, and Nouli runs the supplied decision workflow. No hosted API key is required.

In the first terminal:

Terminal 1 · prepare and serve
hf download nouli-ai/nouli-doom --revision v1.0.0 --local-dir ./nouli-doom
cd nouli-doom
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python prepare.py --input-json examples/input.json
python serve.py --device cpu

Once the server reports ready, open a second terminal in nouli-doom:

Terminal 2 · run the workflow
nouli --config nouli/nouli.toml --store ./.nouli-store \
  workflow run nouli/example-workflow.json --json

This example returns one action for the supplied state. Running an episode also requires the simulator loop to apply actions and provide each next state.

Base models and training data

  • Student: a PPO multilayer perceptron.
  • Teacher: fabiononato/doomfly-rl, checkpoint malecns49k_noconn.

Training data: Teacher trajectories, DAgger and simulator reinforcement learning.

Trained through imitation learning from the public Doomfly teacher and simulator reinforcement learning. Doomfly supplied labels; its weights are not the student's direct initialization. Source revisions and provenance.

Limitations

  • Validated on Deadly Corridor at skill 5 with the supplied state/action wrapper.
  • Inputs include structured state and goal assistance; these results do not establish pixel-only or general Doom performance.
